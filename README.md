# Honey Home Confectionery

Сделай одностраничный сайт кондитерской «Кондитерский дом "Медовый"» из Ростова-на-Дону. Торты на заказ ручной работы.

СТИЛЬ. Тёплый и домашний, но не детский и не приторный. Много воздуха, крупные фотографии тортов — фотографии здесь главный товар, они должны занимать основную площадь экрана. Никаких стоковых картинок и никаких иконок еды из наборов. Скругления крупные, 24–30 пикселей. Заголовки шрифтом с характером, текст простым и читаемым.

ПАЛИТРА: основной тёмно-коричневый #725e54, карамельный #bd8e6b, акцентный жёлтый #ffc700, фон кремовый #fffcf9, розовый #ffaeb7 для мелких деталей.

Сайт должен безупречно работать на телефоне — большинство заказов приходит со смартфонов. Мобильную версию проверь отдельно: ничего не вылезает за край, кнопки крупные, телефон нажимается.
